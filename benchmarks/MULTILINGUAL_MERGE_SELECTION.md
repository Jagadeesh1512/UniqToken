# Multilingual merge selection experiment (#88)

This tokenizer-only experiment tests global, stratum-balanced and coverage-aware
merge selection. It does not assume that balancing improves compression, and it
does not change the default scoring strategy. Results are descriptive evidence
from the recorded corpus, not a claim about all languages or linguistic units.

## Run and retained evidence

Install the test/benchmark dependencies and commit the experiment code first.

```bash
python -m benchmarks.multilingual_merge_analysis \
  --budget 650 --merges 50 --output artifacts/issue88-reviewed
python -m unittest tests.test_multilingual_merge_selection tests.test_multilingual_review_regressions -v
```

The default input is a small controlled fixture with ten language labels.
English and Spanish training paragraphs are repeated eight times; validation
uses separate paragraphs. This is an exposure-skew fixture, not a frozen
real-corpus study or a measurement of the existing Phase A models. Its input
text is defined in the source and bound by the analysis source hash.

`--dataset` accepts an external manifest with train, validation and test entries.
Train/validation file hashes are verified, normalized text and document-ID
overlap is rejected, and split aliases/path escape are rejected before opening
data. The test path and declared hash are metadata only; test is never opened or
hashed. The output must be new and outside the frozen input directory.

The retained [report](multilingual_merges/issue88/REPORT.md), JSON and CSV files
are generated by the same entry point. Their adjacent hash receipt binds their
bytes. Metadata records code/native-extension identity, software versions,
configuration, source and assignment hashes. Frozen Phase A/B/C files are not
modified, and no LM is initialized or trained.

## Comparable conditions

All four evaluated conditions have the same total vocabulary budget, including
the same four controls and 256 byte entries. The full-budget Unigram baseline
uses all slots for Unigram training. The three merge conditions share an
identical smaller Unigram seed and reserve the remaining slots for merges.
An exhausted candidate set that cannot reach the exact budget fails rather
than publishing a mismatched comparison.

Normalization and pre-tokenization are shared across training and evaluation.
Compression denominators use normalized source bytes and Unicode characters,
not the three-byte spelling of a metaspace marker. Every validation token
sequence must reconstruct the normalized source exactly. Raw byte counts remain
available separately; NFKC does not promise raw-byte reversibility.

`merged_token_emissions` counts final emitted pieces present in the learned
merge vocabulary. It is not a count of all intermediate binary applications.
`tokens_saved` is the token-count difference from the full-budget Unigram
baseline and can be negative. Whitespace-field fertility is retained as a
descriptive count, not a universal cross-script linguistic measure.

## Scoring objectives

For a pair `(a,b)`, `f` is its adjacent-pair frequency, `N` is total adjacent
pairs, and `L = log P(a) + log P(b)`. Global scoring minimizes
`f * (L - log(f/N))`. Pair counts include overlapping adjacent occurrences;
they are selection statistics, not realized non-overlapping applications.

The experimental stratum-conditional score for `alpha < 1` is
`sum_s W_s * f_s * (L - log(f_s/N_s))`, with
`W_s = (N_s**alpha / sum_k N_k**alpha) / (N_s/N)`.
Pair totals are clamped to at least one when forming weights for previously
active strata. At `alpha = 1`, the implementation explicitly uses the global
score. This endpoint is a special case: the stratum-conditional expression
alone does not algebraically reduce to the global objective, so continuity at
that endpoint is not claimed.

Coverage-aware scoring multiplies this score by
`1 + coverage_weight * H`, where `H` is pair-occurrence Shannon entropy across
strata divided by the log of the number of initially active strata. Alpha must
be finite in `[0,1]`; the coverage weight must be finite and non-negative.
These are hypotheses about capacity allocation, not proofs of a benefit.

All objectives refresh candidate scores after each merge because global and
per-stratum denominators change even for unaffected streams. Ordering uses
`(score, -frequency, empirical_log_probability, left, right)`. Regression tests
compare 150 deterministic random fixtures to an independent exhaustive global
scorer. The full refresh favors correctness over a throughput claim.

## Allocation and limitations

Each merge records its pair counts by stratum, score, dominant stratum and
unrounded dominance ratio. Tied dominant strata are resolved lexically. A merge
is concentrated if at least 90% of its pair occurrences come from one stratum.
The percentage of concentrated merges is not the percentage allocated to a
single language. HHI describes the distribution of dominant-stratum labels.

The generated tables retain all language strata, all strategies and adverse
compression outcomes. More represented strata, a lower HHI, or a different
allocation does not itself establish improved validation compression. The
small canonical fixture cannot settle real-world multilingual allocation,
causal explanations, morphology, downstream quality or a global best tokenizer.
